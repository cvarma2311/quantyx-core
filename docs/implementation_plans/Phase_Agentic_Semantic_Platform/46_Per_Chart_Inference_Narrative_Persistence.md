# Phase 46 — Per-Chart Inference, Narrative & Stats Persistence

## Overview

Every chart in Quantyx — whether generated by the Dashboard Agent, Anomaly Detection Agent,
Correlation Agent, workspace conversations, background jobs, or direct API calls — should carry
its own human-readable insight, narrative, and descriptive statistics. These are already computed
in some paths (Dashboard Agent) but discarded. This phase persists them universally so the UI
can show a one-liner below each chart without a second round-trip.

---

## Current State

### What exists
- `_chart_insight(chart_type, rows, metric_name, dim_key)` → `{summary, value, type}` — top/delta callout
- `_chart_stats(rows, metric_name)` → `{count, min, max, avg, total}` — descriptive stats
- `_chart_narrative(rows, metric_name, dim_key)` → `{summary, top, bottom}` — best/worst dimension labels

All three live in `services/ai/agentic_orchestrator.py` (lines 2232–2308).

### What's missing
- None of these are persisted to `quantyx_chart_requests`
- `update_chart_request()` has no parameters for insight/narrative/stats
- Anomaly, correlation, workspace, job, and API chart paths don't call these helpers at all

## Target State

### New columns on `quantyx_chart_requests`

| Column | Type | Description |
|---|---|---|
| `insight_text` | `TEXT NULL` | One-line human-readable callout (top value, latest delta, etc.) |
| `narrative_text` | `TEXT NULL` | Best/worst dimension sentence for ranked charts |
| `stats_json` | `JSONB NULL` | `{count, min, max, avg, total}` over the primary metric |

These are intentionally plain text + JSONB — the UI renders `insight_text` directly below the
chart title. `stats_json` feeds tooltip/sparkline overlays. No breaking changes to existing columns.

### Step 3 — Add `_build_chart_inference` shared helper

**File: `services/ai/agentic_orchestrator.py`** (place alongside existing `_chart_insight` / `_chart_stats` / `_chart_narrative`)

```python
def _build_chart_inference(
    chart_type: str,
    rows: list[dict],
    metric_name: str,
    dim_key: str | None,
) -> dict[str, Any]:
    """
    Combines insight, stats and narrative into a single dict suitable for
    persisting to quantyx_chart_requests. Returns:
      {
        "insight_text":   str,   # one-liner for UI display below chart title
        "narrative_text": str,   # best/worst sentence for ranked charts
        "stats_json":     dict,  # {count, min, max, avg, total}
      }
    All fields are always present; empty/unavailable cases return safe defaults.
    """
    insight   = _chart_insight(chart_type, rows, metric_name, dim_key)
    stats     = _chart_stats(rows, metric_name)
    narrative = _chart_narrative(rows, metric_name, dim_key)
    return {
        "insight_text":   str(insight.get("summary") or ""),
        "narrative_text": str(narrative.get("summary") or ""),
        "stats_json":     stats,
    }
```

This is the single call site for all chart paths — no duplication of logic.

## Implementation Order

1. **Step 1** — Schema migration (run `apply_agentic_tables.sh` immediately after)
2. **Step 2** — Extend `update_chart_request` (no risk; all new params are keyword-only with `None` default)
3. **Step 5** — Move helpers to `charts.py` (establishes the shared function before wiring call sites)
4. **Steps 4a–4h** — Wire call sites in order: Dashboard Agent → Anomaly Agent → Correlation Agent → Workspace → Job → Refresh → Rollup/Dimension → Background correlation
5. **Step 6** — Update `get_chart_request` SELECT
6. **Step 7** — Update schema model

Steps 1–3 are prerequisites. Steps 4–7 can proceed in parallel across agents once Step 3 is done.

---

## Non-Goals

- LLM-generated narration per chart (this is deterministic stats only — fast, no latency, no cost)
- Backfilling existing chart rows (inference is only for new chart writes; historical rows get `NULL`)
- Changing `chart_payload` structure (inference is stored in separate columns, not embedded in the spec)
